REAL WORKPLACE INITIATIVE

From manual checks to five-minute infrastructure reporting

Independently replaced repetitive manual collection and formatting with an on-demand, stakeholder-readable infrastructure reporting workflow.

Detailed case study (PDF) ↗

The opportunity

A technical team supporting a banking client prepared multiple server and database health reports three to four times a day, with additional requests when needed. Each run involved moving between Linux or database hosts, executing checks, collecting results and manually assembling output. Preparation typically took an estimated 30–60 minutes.

My ownership and approach

I noticed the repetitive work, designed the workflow and independently built a Linux shell-script solution, using AI assistance for parts of development. The script was invoked on demand, gathered infrastructure indicators and generated timestamped HTML reports in a shared server location. Teammates could run one command instead of repeating individual checks.

Key product decisions & tradeoffs

  • Automate preparation, not diagnosis: Existing infrastructure logs already served diagnostic purposes. A consolidated reporting layer addressed the actual stakeholder need.
  • On demand instead of scheduled: Manual triggering supported regular and ad hoc client requests. Cron scheduling remained a possible enhancement, not a shipped feature.
  • Browser-readable HTML: A consistent report reduced repeated manual consolidation and made outputs easier to share.

Result and evidence

Reporting preparation dropped from approximately 30–60 minutes to around five minutes per run, an estimated 83–92% reduction. The solution was used regularly by the team while I worked there. Roughly ten members had access; individual usage counts were not measured.

What I'd improve next

Add clearer failure states and freshness indicators; establish a lightweight timing log; consider optional scheduled generation alongside on-demand access if operational needs justify it. All public examples should remain sanitized of client and infrastructure identifiers.
